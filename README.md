# 🚀 AI 自动分类桌面浮动窗

一款基于 Electron 的桌面浮动窗应用，输入任意文本即可自动分类并记录到对应分类中。

## 📸 功能预览

```
输入 "我要做个软件"     → 📋 任务 (可勾选完成)
输入 "我有个好想法"     → 💡 想法 (可扩展笔记)
输入 "邮箱 xxx 密码 yyy" → 🔑 账号 (密码掩码、一键复制)
输入 "https://..."      → 🔗 链接 (点击直达)
输入 "今天心情很好"     → 📔 日记 (情绪图标)
输入 "推荐一本书"       → 📚 待读 (进度追踪)
输入 "他说过..."        → 📜 语录 (引用样式)
输入 "记住这个..."      → 📝 备忘 (便签)
```

## 🎯 核心特性

### 🤖 智能分类引擎
- 基于关键词 + 正则的智能匹配算法
- 8 种预设分类类型，覆盖日常场景
- 可自定义分类规则
- 自动优先级检测（紧急/重要/普通）

### ✨ 类型专属操作

| 类型 | 图标 | 颜色 | 专属功能 |
|------|------|------|---------|
| 📋 任务 | 📋 | 🔵 | 复选框勾选、优先级标记、完成状态 |
| 💡 想法 | 💡 | 🟡 | 延伸笔记、想法扩展树 |
| 🔑 账号 | 🔑 | 🟢 | 密码掩码、悬停显示、一键复制、自动解析 |
| 📝 备忘 | 📝 | 🟣 | 标签分类 |
| 🔗 链接 | 🔗 | 🔴 | 点击直达、自动提取URL |
| 📔 日记 | 📔 | 🟠 | 情绪检测、日期标记 |
| 📚 待读 | 📚 | 🟢 | 阅读进度追踪 |
| 📜 语录 | 📜 | 🟤 | 引用样式、作者标记 |

### 🖥️ 交互体验
- **毛玻璃浮动窗** - 始终置顶，不干扰工作
- **一键展开/收缩** - 紧凑模式只留输入栏
- **分类选项卡** - 按类型筛选查看
- **全文搜索** - 快速检索所有记录
- **拖拽移动** - 任意位置随意拖动
- **键盘快捷键** - `Ctrl+Shift+Space` 快速隐藏/显示
- **暗色模式** - 自动适配系统主题
- **数据持久化** - 自动保存到本地

## 🚀 快速开始

### 环境要求
- Node.js >= 18
- npm >= 8

### 安装运行

```bash
# 克隆仓库
git clone https://github.com/zhaoxv210/floating-ai-classifier.git

# 进入目录
cd floating-ai-classifier

# 安装依赖
npm install

# 启动应用
npm start
```

### 快捷键
| 快捷键 | 功能 |
|--------|------|
| `Enter` | 提交输入文本 |
| `Ctrl+Shift+Space` | 显示/隐藏浮动窗 |
| 双击 `📂` | 展开/收缩面板 |
| 拖拽 `⋮⋮` | 移动窗口位置 |

## 🛠️ 技术栈

- **Electron 28** - 跨平台桌面框架
- **HTML5 + CSS3** - 毛玻璃效果、动画过渡
- **Vanilla JavaScript** - 零依赖核心逻辑
- **JSON 文件存储** - 用户目录下的 `.floating-classifier/data.json`

## 📤 数据安全

- 所有数据存储在本地：`~/.floating-classifier/data.json`
- 账号密码采用掩码显示，悬停才可见
- 无网络请求，数据完全离线
- 可手动导出/备份数据文件

## 🧩 可扩展

### 添加新的分类类型
编辑 `classifier.js` 中的 `DEFAULT_RULES` 对象即可添加：

```javascript
shopping: {
  label: '🛒 购物',
  icon: '🛒',
  color: '#FF6B6B',
  keywords: ['买', '购物', '下单', '商品'],
  patterns: [/想(买|入手|下单)(.*)/i],
  actions: ['price', 'link']
}
```
